# landen/

Per land (NL, BE, LUX, DE) een eigen map met wat de controles bijhouden, bijv. `kolom_o_gemeld.json`
(welke rijen zonder of met foute waarde in kolom O al in Discord gemeld zijn). Welke sheets bij een land horen
staat in `config/sheets.json`. De mappen worden door de uurlijkse run zelf aangemaakt.
